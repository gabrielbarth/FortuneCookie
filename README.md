## Features
- Generate luck message from AI (using [groq](https://console.groq.com/docs/overview));
- Set Portuguese and English languages;
- Set light and dark themes;

## Get started
1. Install dependencies

   ```bash
   npm install / yarn install
   ```

2. Start the app

   ```bash
    npx expo start
   ```
